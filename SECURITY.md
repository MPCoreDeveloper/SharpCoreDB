# Security Policy

## Supported Versions

Only the **V2 line** of SharpCoreDB is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in SharpCoreDB, please report it **privately**.

### How to report
Please use GitHub’s private vulnerability reporting feature:

➡️ [Report a vulnerability](https://github.com/MPCoreDeveloper/SharpCoreDB/security/advisories/new)

### What to expect
- We will acknowledge your report A.S.A.P. and within **48 hours**.
- You will receive regular updates on the status of your report (at least once per week).
- If the vulnerability is confirmed:
  - We will work on a fix as quickly as possible.
  - A security advisory and patched release will be published once the fix is ready.
- If the report is declined, we will explain the reason.

### Scope
- Only vulnerabilities affecting the **V2 line** will be considered.
- Versions below 2.0 are no longer supported and will not receive security updates.

Thank you for helping keep SharpCoreDB secure.
