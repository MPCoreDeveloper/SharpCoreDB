# SharpCoreDB 2.0.0.3 — What changed

- **Release:** `2.0.0.3` (2026-09-12) — patch maintenance release on the 2.0.0.x line.
- **Quality gate:** CI-filtered core suite **1679 tests / 0 failed**, full CI solution builds with
  **0 errors** on Windows.
- **Contents:** everything merged since 2.0.0.2 — the SonarCloud cognitive-complexity refactor
  batch and the NuGet dependency update batch. **No public-API changes, no storage-format changes,
  no behavior changes.**
- See `docs/CHANGELOG.md` → `[2.0.0.3]` for the change list and
  `docs/2.0.0.2_WHAT_CHANGED.md` for the previous release's engine report.

## 1. Code quality (no behavior change)

- **SonarCloud S3776 “quick-win” refactors** — 13 methods above the cognitive-complexity threshold
  were reduced to below it by pure method extraction across the core engine and the comparative
  benchmark harness: `BTree.DeleteFromNode`, `HashIndex.AddBatchKeys`, `ColumnStore.Aggregates`
  SIMD kernels, `Storage.Append` tombstone/overwrite/read-all paths, `Table` index-rebuild and
  fixed-width-migration helpers, serialization slot writes, `Table.CRUD.IsFilePkOrderedUpTo`, and
  the benchmark `Main`/`RunInsertMicroBenchmark` harness. Behavior and hot-path shape are
  unchanged; the JIT-inlinable helpers keep the same allocations (verified by the full suite).
